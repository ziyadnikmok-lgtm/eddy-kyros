# Design: Prompt Enhancer + Quality Scorer

Generated by /plan-ceo-review + /plan-eng-review on 2026-03-18
Branch: main | Mode: SCOPE EXPANSION

## Vision

Prompt enhancement makes every generation smarter. Quality scoring auto-curates your best work. Together they cut wasted generations and make output quality dramatically more consistent. Your hit rate goes from 1-in-5 to 4-in-5.

## Two Accepted Features

### 1. Prompt Enhancer / Auto-Improve
- **UI:** Toggle switch on GeneratePage, shows before/after prompt diff
- **Flow:** User types prompt → toggle "Enhance" → POST /api/prompt/enhance → Gemini rewrites with technical details → user accepts/edits/rejects → continues to generate
- **Integration:** New `geminiService.enhancePrompt()` method, optional step in generate route
- **Edge cases:** Empty prompt (skip), rapid toggle (debounce 500ms), enhanced prompt too long (truncate to 15K), Gemini failure (fallback to original)

### 2. AI Best-Pick & Quality Scorer
- **UI:** Star badges on gallery thumbnails, "Sort by quality" option
- **Flow:** After batch completes → POST /api/batch/:id/score-picks → Gemini analyzes images for composition, identity consistency, aesthetic appeal → scores 0-100 → badges on top picks
- **Integration:** New `geminiService.scoreImageQuality()` method, new route in batch.js, `galleryManager.updateMetadata()` for persisting scores
- **Edge cases:** >10 images (score top 10 only), NSFW safety block (skip scoring), malformed JSON (score=null), parallel scoring with concurrency cap of 3

## Architecture

```
CLIENT (React)
├── GeneratePage.jsx + EnhanceToggle (NEW)
│   → POST /api/prompt/enhance { prompt, context }
├── GalleryPage.jsx + QualityBadge (NEW)
│   → Score data in gallery metadata (qualityScore, qualityReasons)
└── BatchPage.jsx + "Score Picks" button (NEW)
    → POST /api/batch/:id/score-picks

SERVER (Express)
├── routes/generate.js → optional enhancePrompt step before generation
├── routes/batch.js → POST /:id/score-picks (NEW)
├── services/geminiService.js
│   ├── REFACTOR: _generateTextInner() — shared retry/timeout/parse logic
│   ├── NEW: enhancePrompt(apiKey, rawPrompt, context)
│   └── NEW: scoreImageQuality(apiKey, imageBase64, criteria)
└── services/galleryManager.js
    ├── NEW: updateMetadata(id, patch) — generic metadata update
    └── MODIFIED: _toSafe() — expose qualityScore, qualityReasons, parentId
```

## Eng Review Decisions

| # | Decision | Choice | Reasoning |
|---|----------|--------|-----------|
| 1 | Gallery metadata updates | `updateMetadata(id, patch)` | Generic, reusable for scores + future metadata |
| 2 | Inpainting | REMOVED from scope | Gemini lacks native mask API; deferred to TODOS |
| 3 | DRY in geminiService | Extract `_generateTextInner()` | Eliminates 120 lines of duplication across text gen methods |
| 4 | Test coverage | All 7 new codepaths | Tests are the cheapest lake to boil |
| 5 | Scoring parallelism | Promise.all with concurrency cap 3 | 3-10s instead of 10-30s |

## Key Implementation Notes

- Both features use Gemini text API — no new external dependencies
- Quality scoring capped at 10 images per batch to control API costs
- Prompt enhancement is fully opt-in (toggle off by default)
- All new Gemini calls integrate with existing spend tracking
- Error handling: catch safety blocks, timeouts, malformed responses — fallback gracefully
- DRY refactor: extract `_generateTextInner()` so generateText, generateTextWithSearch, enhancePrompt, and scoreImageQuality all share retry/timeout/parse logic
