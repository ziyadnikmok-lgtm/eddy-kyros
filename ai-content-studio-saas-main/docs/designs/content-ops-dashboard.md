# CEO Plan: Design Polish + Spend Tracking + Gallery Ops + Content Dashboard

## Vision

### 10x Check
A full Content Operations Dashboard that shows pipeline health — spend, character performance, session history, and auto-suggests next content batches. Gallery becomes a smart media library with sessions, keyboard nav, and carousel export. Cost awareness embedded in every generate button. Budget alerts prevent surprise lockouts.

### Platonic Ideal
When you open the app, you see: "You generated 47 images yesterday for $6.32. Lynn outperformed Maria 3:1. Your top style was 'golden hour beach' — want 10 more?" Every screen has exactly the right information. Cost is never a surprise. Gallery feels like Lightroom. The entire content pipeline is visible in one view.

## Accepted Scope (added to this plan)
- Cost estimates on every Generate button (image, batch, carousel, scene, post clone, reel)
- Budget alert toasts at 50%, 80%, 95% thresholds
- Spend sparkline in sidebar nav next to API Keys
- AI-generated session names via Gemini when batch completes
- Gallery keyboard navigation (arrows, Enter, Delete, S, E)
- "Send to Carousel" button on gallery session groups
- "Undo last batch" with automatic spend counter refund
- Content Operations Dashboard as new homepage
